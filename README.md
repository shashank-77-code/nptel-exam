# NPTEL Research Methodology Study Studio

A self-contained static study guide for the IIT Madras NPTEL Research Methodology course.

## Run locally

Open `index.html` in a browser. No build step or backend is required.

## Deploy

This folder can be imported directly as a static project in Vercel. The root directory is this folder; no build command or output directory is needed because `index.html` is at the project root.

## Content notes

The practice questions are original syllabus-based revision questions. They are not verified past exam questions and do not predict exam content. The course outline and references are linked from within the app.
